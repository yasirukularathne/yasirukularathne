## Featured Projects

### Interpretable AI for 3D Pulmonary CT Analysis
Final Year Project developing explainable deep learning methods for 3D chest CT, aimed at making model predictions transparent and clinically meaningful.
**Focus:** Medical imaging, explainability, deep learning

### Multi-Layer Network Intrusion Detection
A layered machine learning pipeline for network intrusion detection on the ISCX-IDS2017 dataset, combining gradient boosting, transformer-based, and autoencoder models, served through a Flask API.
**Stack:** Python, XGBoost, BERT, Autoencoders, Flask

### [HPC DNA Sequence Similarity Search](https://github.com/yasirukularathne/HPC_DNA)
DNA sequence similarity search implemented in C across serial, OpenMP, MPI, and hybrid parallel versions, with performance comparison between approaches.
**Stack:** C, OpenMP, MPI

### [Rainfall Prediction in Galle, Sri Lanka](https://github.com/yasirukularathne/rainfall-prediction-galle)
Regression models (Linear Regression and Random Forest) trained on historical weather data. The Random Forest model reached an R² of 0.83, supported by thorough preprocessing, feature engineering, and hyperparameter tuning.
**Stack:** Scikit-learn, Pandas, Seaborn, Matplotlib
