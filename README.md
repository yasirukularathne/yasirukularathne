### Enterprise RAG & AI Platform
An AI platform that retrieves information from organizational documents and produces grounded, cited responses using Retrieval-Augmented Generation.

- **Pipeline:** document ingestion, chunking, embeddings, vector search, LLM generation with source citations, and evaluation
- **Stack:** Python, FastAPI, PostgreSQL, Vector Database, React, Docker

### Multilayer AI Intrusion Detection System
A cybersecurity system that combines machine learning, NLP, and AI-generated explanations to detect and analyze network threats.

- **Capabilities:** network traffic classification, NLP-based threat analysis, anomaly detection, AI-assisted explanations
- **Stack:** Python, XGBoost, BERT, FastAPI, React, MCP, LLM

### [Kafka Event-Driven Order Processing System](https://github.com/yasirukularathne/kafka-order-system)
A distributed order-processing system demonstrating event-driven architecture on Apache Kafka.

- **Concepts:** producers and consumers, topic partitioning, consumer groups, retry mechanisms, Dead Letter Queue, schema-based messaging
- **Stack:** Python, Apache Kafka, Docker, Avro, Fastavro

### Interpretable 3D Chest CT AI
Final-year research project generating interpretable diagnostic hypotheses from 3D chest CT data using dictionary learning.

- **Research areas:** 3D CT analysis, sparse coding, medical image classification, explainable AI
- **Stack:** Python, PyTorch
